# Golden State Routes - COMP 584 Project 3

This project converts the Golden State Routes responsive travel guide from Flexbox to CSS Grid. The content and visual theme are retained while every layout uses Grid.

## CSS Grid features

- Mobile-first responsive Grid layouts
- Four equal desktop columns with `repeat()` and `minmax()`
- Grid items that span one, two, three, or all four columns
- A named `grid-template-areas` layout that changes between tablet and desktop
- Nested Grid layouts for horizontal feature cards
- A responsive five-item checklist using `auto-fit` and `minmax()`
- Comments explaining properties that were not covered in the Week 6 lecture
